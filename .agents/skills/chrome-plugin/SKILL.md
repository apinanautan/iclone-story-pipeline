# ปลั๊กอิน Chrome: AI ดูแลเอง ผู้ใช้ไม่ต้องจำ (ผู้ใช้ 2026-11-28)

## อัปเดต: ไม่ต้องทำอะไร
- ทุกคำสั่ง `Ai-iclone ...` ทำให้เอง: เปิดตัวเชื่อม (relay) ถ้ายังไม่เปิด เปลี่ยน relay ตัวเก่าเป็นตัวใหม่ คัดลอกไฟล์ปลั๊กอินใหม่ไปโฟลเดอร์ที่ Chrome โหลดอยู่ แล้วปลั๊กอิน reload ตัวเองภายใน 1 นาที
- ห้ามบอกผู้ใช้ให้โหลดหรือติดตั้งปลั๊กอินเอง ถ้าโปรแกรมไม่ได้พิมพ์ว่าต้องทำ

## ตรวจ
- `Ai-iclone setup` หรือ `Ai-iclone` (ไม่ใส่อะไร) มีบรรทัด "ปลั๊กอิน Chrome"
  - `OK` = ใช้ได้
  - `..` = กำลังอัปเดตตัวเอง รอ 1 นาที ไม่ต้องทำอะไร
  - `--` = Chrome ปิดอยู่ หรือไม่ได้เปิด chatgpt.com
  - `FAIL` = รุ่นเก่ามาก (0.4.x) อัปเดตตัวเองไม่ได้: บอกผู้ใช้ข้อความในบรรทัดนั้นตรงๆ (กด reload ครั้งเดียว) ถ้ามีเครื่องมือคุมหน้าจอ ทำแทนได้: เปิด `chrome://extensions` กดปุ่ม reload (ลูกศรวน) ที่ "iClone Preview to Chat"
- ห้ามปิด Chrome เอง: แชตที่ใช้อยู่ก็อยู่ใน Chrome

## ปุ่มติดตามงาน (ส่งข้อความเตือนทุก 30 วินาที)
- หยุดเองเมื่อ: โปรแกรมขึ้น STOP, ถึงจุดรอผู้ใช้ (user_ok), ท่อนเสร็จ
- ถ้าข้อความติดตามมีรหัส `ACHIEVEMENT: XXXXXXXX-XXX` และงานถึงเป้าแล้ว:
  1. ถ้ามีเครื่องมือรันคำสั่งบนเครื่อง: `py -3 -B tools/chrome_preview_bridge/goal_signal.py XXXXXXXX-XXX` ครั้งเดียว ไม่ต้องรันซ้ำ
  2. ทุกกรณี จบคำตอบด้วยบรรทัดรหัสนั้นเดี่ยวๆ แล้วหยุด ไม่ต้องตรวจซ้ำ ไม่ต้องแก้ relay
- ห้ามเดารหัส ห้ามใช้รหัสจากแชตเก่า

## ข้อความผิดพลาดใน popup
- "ต่อโปรแกรมในเครื่องไม่ได้" = รันคำสั่ง `Ai-iclone` อะไรก็ได้ (เช่น `Ai-iclone`) relay จะเปิดเอง
- "แชตที่รับภาพ: แชตอื่น" หรือ "ยังไม่ผูก" = พิมพ์บรรทัดรหัสแชตจาก Ai-iclone ลงในคำตอบ (ดูข้างล่าง)

## ภาพจาก iClone มาถึงแชตยังไง (ผู้ใช้ไม่ต้องกดอะไร)
- AI สั่ง `Ai-iclone ...` ตามขั้น โปรแกรมจับภาพ Preview ให้เอง ปลั๊กอินแนบภาพและกดส่งเข้า "แชตที่ผูกไว้" เอง
- `Ai-iclone` และ `Ai-iclone do` พิมพ์บรรทัด "รหัสแชต ... [iClone Handoff <รหัส>]" AI ต้องคัดลอกส่วน `[iClone Handoff <รหัส>]` ลงในคำตอบของตัวเองครั้งเดียวต่อแชต ปลั๊กอินเห็นแล้วผูกแชตนี้เอง
- แชตที่เริ่มจากปุ่ม copy prompt ของปลั๊กอิน หรือจาก Sleep Mode ผูกเองอยู่แล้ว
- ไม่มีปุ่ม "ผูกแชตนี้" แล้ว ห้ามบอกผู้ใช้ให้ผูกเอง

## ส่งภาพ iClone ตอนนี้แบบอิสระ: `Ai-iclone snap`
- จับภาพหน้าต่าง iClone ที่เปิดอยู่ (โปรเจกต์ไหนก็ได้ เช่น กำลังทำฉาก ทดสอบ หรือฉากที่ยังไม่เป็นท่อน) แล้วส่งเข้าแชตที่ผูกไว้
- ไม่มีเงื่อนไขเรื่อง/ท่อน ไม่ติด "wrong live project" ใช้ทุกครั้งที่อยากดูงานตัวเอง
- ภาพนี้ไม่นับเป็นหลักฐานตรวจท่อน การตรวจท่อนยังใช้ขั้นใน Preview (`Ai-iclone do`) เหมือนเดิม
- ถ้าขึ้น "waiting: write this line…" ให้พิมพ์บรรทัด `[iClone Handoff …]` นั้นลงในคำตอบ 1 ครั้ง แล้วจบคำตอบ ปลั๊กอินจะผูกแชตนี้และส่งรูปที่ถือไว้เข้ามาเอง ไม่ต้อง snap ใหม่ ไม่ต้องเปิดเรื่อง
