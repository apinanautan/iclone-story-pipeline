# Blender ทำอะไรให้โปรเจกต์นี้ได้บ้าง

ผู้ใช้ขอเมื่อ 2026-11-28 ให้มีเอกสารที่จับต้องได้ บอกว่า Blender ทำอะไรได้จริง AI จะได้รู้เองโดยไม่ต้องสั่งทีละอย่าง

สถานะในตาราง:
- ✅ ทดลองในเครื่องนี้แล้ว ใช้ได้
- 🟡 มีเครื่องมือครบแล้ว แต่ยังไม่ได้ทดลองครบทั้งรอบกับ iClone จริง
- ⬜ ยังไม่มี

## สิ่งที่ติดตั้งอยู่แล้ว (ตรวจเมื่อ 2026-11-28)
| ฝั่ง | ปลั๊กอิน | ใช้ทำอะไร |
|---|---|---|
| iClone 8 | **Blender Pipeline Plugin** (Plugins > Blender Pipeline) | Data Link ส่งตัวละคร พร็อพ โมชั่น กล้อง และแสงไป Blender และรับแอนิเมชันกลับ (TCP พอร์ต 9333) |
| Blender 5.3 | **CC/iC Tools 2.4.4** (`cc_blender_tools`) | รับของจาก iClone ตั้งค่าวัสดุให้อัตโนมัติ และส่ง Pose/Sequence กลับ iClone |
| Blender 5.3 | Blender MCP | ให้ AI สั่ง Blender ที่เปิดอยู่ได้ตรงๆ (การค้นคลัง Poly Haven ใน MCP ยังปิดอยู่) |

Blender อ่านไฟล์ .iMotion/.rlMotion ของ iClone ตรงๆ ไม่ได้

**⚠ เครื่องนี้ไม่มี FBX Export License (ทดลอง 2026-11-28):** Export FBX และ Data Link "Send Motion"/"Send Character" ขึ้นข้อความ "You must first purchase the Export Licenses" แล้วไม่ได้ไฟล์ จึงใช้วิธีอ่านกระดูกตรงจาก iClone แทน (ไม่ต้องใช้ license) ส่วนการ **นำเข้า** FBX เข้า iClone ยังทำได้

## 1. โมชั่น: iClone → Blender → iClone
| ขั้น | วิธี | สถานะ |
|---|---|---|
| อ่านจาก iClone | `python scripts/motion_blender.py actor <ชื่อนักแสดง> [fps]` ส่งงานให้ตัวรับงานใน iClone อ่านตำแหน่งและการหมุนของกระดูกหลัก 16 ชิ้น ทีละเฟรม แล้วพิมพ์ผลภาษาไทย | ✅ ท่อน6 แม่สื่อ: นงรักษ์และพิมพา 65 วินาที 1952 เฟรม ใช้ประมาณ 2 นาทีต่อคน ผ่านทั้งคู่ |
| ภาพเดียว | Blender วาดหุ่นเส้นของเฟรมที่ถูกเตือน (ไม่มีเฟรมเตือนก็วาด ต้น/กลาง/ท้าย) ลงภาพเดียว `progress/motion_analysis/actor_*.png` แทนการแคปจอหลายภาพ | ✅ |
| อ่าน FBX | `python scripts/motion_blender.py check <motion.fbx>` สำหรับ FBX จากคลังหรือจาก Blender (จับกระดูก CC_Base/Mixamo/ชื่อทั่วไปให้เอง) | ✅ ฟ้อนรำ.fbx 550 เฟรม 5 วินาที |
| แก้ | แก้ท่าใน Blender บนโครงกระดูก CC ตัวเบส แล้ว export FBX จาก Blender (Blender export ได้ ไม่ติด license) | 🟡 |
| ส่งกลับ | นำเข้า FBX เข้า iClone ด้วย Import Motion (`tools/motion_ai/ic_imp2.ps1`, กด Convert All) ลงนักแสดงตัวเดิม เคยทำสำเร็จกับท่าถือถ้วยรางวัล (`tools/motion_ai/retarget.py`) | 🟡 ยังไม่ได้ทดลองรอบนี้ |
| Data Link ส่งกลับแบบสด | Blender > Data Link > Send Animation Sequence ต้องส่งตัวละครจาก iClone ไปก่อน แต่ตอนนี้ติด license | ⬜ |

ข้อควรรู้:
- ตรวจโมชั่นไม่ต้องใช้เสื้อผ้าหรือผม (ผู้ใช้ 2026-11-28): วิธี `actor` อ่านแค่กระดูกอยู่แล้ว ถ้าต้องโหลดตัวละครมาลองท่าใหม่หรือแก้ท่า ให้ใช้ตัวเบสเปล่าจาก Public Documents > Reallusion > Reallusion Templates > Actor > Character (โฟลเดอร์ Base, Motion Dummy, Mannequin หรือ CC4 Kevin/Camila/Susan)
- เกณฑ์ตั้งต้นอยู่ใน `LIMITS` ของ `scripts/motion_blender.py`
- ท่าที่ตั้งใจให้เดิน (เช่น ฟ้อนเดิน) จะถูกเตือนว่าตัวเลื่อน ต้องดูว่าตรงบทไหม ห้ามแก้ตามตัวเลขอย่างเดียว
- การอ่านแค่เลื่อน playhead ไม่แก้ฉาก (ชื่อไฟล์จะมี * แต่ไม่ต้องเซฟ) ต้องเปิด iClone = ถามผู้ใช้ก่อน และห้ามทำระหว่างที่แชตอื่นคุม iClone
- ไม่ทิ้งขยะ: ไฟล์ชั่วคราวลบเอง `progress/motion_analysis` เก็บล่าสุด 30 ผลเท่านั้น

## 2. พร็อพที่บทพูดถึงแต่ฉากไม่มี
ตัวอย่าง: ฉากร้านเสริมสวยต้องมีกรรไกร โต๊ะทำผม กระจก เก้าอี้ และหวี

**เลือกวิธี (ผู้ใช้ 2026-11-28):**
- พร็อพชิ้นเล็กไว้โชว์ที่ไม่ต้องละเอียดสูง เช่น ทีวี ตู้เย็น ตู้เสื้อผ้า ตะกร้า → **image-to-3D ผ่าน Tidmunz Studio** (รูปทุกอย่างดึงหรือสร้างใน Tidmunz Studio)
- ฉาก ผนัง โดยเฉพาะบ้านทั้งหลัง → **Blender** ต่อบล็อกสี่เหลี่ยม หลังคา ฯลฯ เพราะ image-to-3D ซูมเข้าไปข้างในหรือดู texture ใกล้ๆ แล้วแปลก จากนั้นตกแต่งข้างในด้วยพร็อพ image-to-3D
| ขั้น | วิธี | สถานะ |
|---|---|---|
| หาของเดิมก่อน | ค้นคลังพร็อพ iClone และคลัง Tidmunz ก่อน | ✅ |
| สร้าง | เขียนสคริปต์โมเดล (ขนาดเป็นเมตร มี bevel, UV และวัสดุ PBR) แล้วรัน `python scripts/blender_prop_build.py <model.py> <โฟลเดอร์ใหม่>` ได้ `.blend`, `model.fbx` และ QA | ✅ เคยทำกรรไกร หวี โต๊ะ ถ้วยรางวัล และเวทีมาแล้ว |
| เข้า iClone | ใส่ใน `props` ของสเปกท่อน (fbx, pos, yaw, scale) ให้ขั้น props นำเข้า (Convert All) หรือใช้ Data Link Send Prop จาก Blender | ✅ ขั้น props มีอยู่แล้ว (ทุกชิ้นต้องตรวจขนาดใน iClone อีกครั้ง) |
| ตรวจ | ดูภาพจาก iClone จริงในช็อตที่เห็นพร็อพ | ✅ |
รายละเอียดวิธีทำอยู่ใน skill `.agents/skills/blender-prop-production/SKILL.md`

## 4. Texture ฟรีจากเน็ต
ใช้เฉพาะเว็บที่แจกแบบ **CC0** (ใช้ได้ทุกงาน ไม่ต้องให้เครดิต):
| เว็บ | มีอะไร | ดึงอัตโนมัติ |
|---|---|---|
| Poly Haven (polyhaven.com) | texture, HDRI และโมเดล | มี API: api.polyhaven.com |
| ambientCG (ambientcg.com) | texture PBR | มี API: ambientcg.com/api/v2 |
| ShareTextures (sharetextures.com) | texture และโมเดล | ไม่มี ต้องโหลดเอง |
| cgbookcase (cgbookcase.com) | texture | ไม่มี ต้องโหลดเอง |

กติกา:
- เก็บไฟล์ไว้ในโฟลเดอร์ของพร็อพนั้น และจดชื่อเว็บกับลิงก์ไว้ใน `asset_receipt.json`
- ใช้ไฟล์ PNG/JPG ขนาด 1K–2K พอ (ใหญ่กว่านี้ทำให้ iClone ช้า)
- สถานะ 🟡: ยังไม่ได้ต่อการดาวน์โหลดอัตโนมัติเข้ากับ `blender_prop_build.py` ตอนนี้ต้องโหลดทีละไฟล์
