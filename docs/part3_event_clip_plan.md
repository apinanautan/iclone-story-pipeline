# Part 3 Event-Clip Plan — ดวงเมียน้อย

**CURRENT PLAN (2026-11-11)** — supersedes the long-timeline / 8-shot production structure in docs/part3_rebuild_v1.md.

The rejected approach built about 72 seconds as one iClone timeline and tried to solve standing dialogue, departure, reactions and walk-home movement inside one project.

The required approach is:
**complete one dramatic event -> QA -> save -> render/check -> then start the next event.**

Times are NOT hard-coded event boundaries. Align each event to real script/audio only after identifying the actual event transition.

## 3.1 — Standing conversation / confrontation
Main event: characters remain in the conversation; father delivers his dialogue through the end of that event.

May contain multiple camera shots/reactions:
- father MCU/CU while speaking
- mother reaction
- OTS back to father
- children reaction when meaningful
- father finishes line
- mother absorbs it

These are coverage, NOT new numbered clips.

Requirements:
- speaker visible at meaningful dialogue beats
- correct lip-sync
- facial acting for speaker/listeners
- correct eyelines
- small natural body shifts
- no gratuitous wide/full-body group frame
- end only when the conversation event really resolves

Deliverables:
- 3.1.iProject
- after render approval: 3.1_preview480.mp4
- inspect rendered video before starting 3.2

## 3.2 — Father + mistress decide and walk away
New event because action changes from standing conversation to leaving.

Performance:
- previous line/event finishes
- pause / emotional decision
- gaze disengages
- breath/prep
- weight shift
- head turns first
- shoulders/hips follow
- planted foot
- first step
- mistress reads cue and follows with offset timing
- walking progression

Coverage inside 3.2 may include decision close-up, turn prep, first step, mother/children reaction cutaway, and return to father/mistress farther along path.
Do not show a long rear-view walk merely to prove every metre happened.

Deliverables:
- 3.2.iProject
- after approval: 3.2_preview480.mp4
- QA stand->turn->walk, root, foot phase, screen direction, framing

## 3.3 — Mother + children aftermath / comfort
New event: father has left the immediate interaction; story focus becomes mother and children.

Possible beats inside SAME clip:
- mother watches departure
- processing pause
- gaze moves to child
- first child responds
- second child responds later
- mother approaches/leans/comforts
- shoulder contact / protective embrace / believable contact
- children react

Do not split each reaction into another file.

Deliverables:
- 3.3.iProject
- after approval: 3.3_preview480.mp4
- QA face/contact/hands/eyeline/emotional resolution

## 3.4 — Mother leads children home
Create 3.4 only if comfort is complete and a distinct new movement event begins: go home.

Performance:
- mother looks toward destination
- decision
- weight shift
- head/shoulder/hip turn
- first step
- children follow with staggered timing and non-identical stride
- travel
- purposeful closing image

Deliverables:
- 3.4.iProject
- after approval: 3.4_preview480.mp4
- QA first step, child timing, root, framing, closing payoff

## Assembly
Only after every event passes:
3.1 + 3.2 + 3.3 (+3.4) -> Part 3 master

Verify:
- no duplicated/missing words
- no unnatural silence/audio jump
- no repeated frames/actions
- no screen-direction discontinuity
- no lip-sync shift at joins
- clean emotional progression
