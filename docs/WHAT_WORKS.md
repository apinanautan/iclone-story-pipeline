# ทำอะไรได้แล้ว / ยังไม่ได้ (อัปเดตทุก Release)

ผู้ใช้ 2026-11-28: แค่บอก AI ว่า "อ่าน GitHub" แล้ว AI ต้องรู้เองว่าทำอะไรไปแล้ว ผู้ใช้ไม่ต้องจำ
AI ที่แก้โปรแกรมต้องอัปเดตไฟล์นี้ทุกครั้งที่ออก Release

สถานะ: ✅ ใช้ได้ (ทดลองแล้ว) · 🟡 มีของแล้วแต่ยังไม่ได้ทดลองครบ · ⬜ ยังไม่มี

## ลงเครื่องใหม่
| อะไร | สถานะ |
|---|---|
| โหลด `Ai-iclone.exe` จากหน้า Releases แล้วสั่ง `Ai-iclone.exe setup` ครั้งเดียว: โหลดโปรแกรมล่าสุด ตรวจเครื่องมือ หาโฟลเดอร์ของเครื่อง ติดตั้งตัวรับงาน iClone แล้วบอกเป็นภาษาไทยว่าเหลืออะไรที่ต้องทำเอง | ✅ |
| อัปเดตเอง: ทุกคำสั่งเช็ก Release ใหม่ (ไม่เกินทุก 10 นาที) หรือสั่ง `Ai-iclone.exe update` | ✅ |
| ปลั๊กอิน Chrome อัปเดตเองตาม Ai-iclone: relay เก่าถูกเปิดใหม่ ไฟล์ใหม่ถูกคัดลอกไปโฟลเดอร์ที่ Chrome โหลด ปลั๊กอิน reload ตัวเอง | ✅ ทดลองบนเครื่องนี้ (ต้อง reload ด้วยมือครั้งเดียวจาก 0.4.x) |
| AI รู้เรื่องปลั๊กอินเอง: skill `chrome-plugin` แนบไปกับ prompt, `Ai-iclone` / `setup` บอกบรรทัด "ปลั๊กอิน Chrome" OK/FAIL | ✅ |
| ปลั๊กอิน Chrome บนเครื่องใหม่: setup สร้างโฟลเดอร์สะอาด `%LOCALAPPDATA%\Ai-iclone-Chrome` และกุญแจ relay ให้ ผู้ใช้กด Load unpacked โฟลเดอร์นั้นครั้งเดียว | ✅ บนเครื่องนี้ · 🟡 ยังไม่ได้ลองเครื่องอื่น |
| ลงโปรแกรมที่ต้องซื้อหรือต้องล็อกอิน (iClone 8, ปลั๊กอินที่ต้องซื้อ) ทำแทนไม่ได้ ผู้ใช้ต้องลงเอง | — |

## ทำนิทานทีละท่อน
| อะไร | สถานะ |
|---|---|
| ขั้นใน Preview ทีละข้อ (`Ai-iclone do`) AI ทำตามขั้นอย่างเดียว ห้ามเลือกสคริปต์เอง (`AGENTS.md`) | ✅ |
| ขั้นที่ล้มเหลว: โปรแกรมพิมพ์ "ทางซ่อม" บรรทัดเดียว นับถอยหลังจำนวนครั้งซ่อม ไม่วนซ้ำไม่จบ | ✅ |
| ปลั๊กอิน Chrome 0.5.0: กล่องสถานะบนสุด ข้อความภาษาไทย อัปเดตตัวเองโดยไม่ต้องกด reload (ครั้งแรกจาก 0.4.21 ต้องกด reload หรือเปิด Chrome ใหม่ 1 ครั้ง) | ✅ ทดลองหน้าจอแล้ว |
| ปุ่มติดตามงาน (0.5.1): หยุดเองเมื่อโปรแกรมขึ้น STOP / ถึงจุดรอผู้ใช้ / ท่อนเสร็จ / AI พิมพ์รหัส (แม้เป็น `code`) / AI รันสคริปต์หยุด | ✅ ทดสอบโค้ดตรวจรหัสในหน้าจำลองและ relay จริงแล้ว · 🟡 ยังไม่ได้ดูหยุดจริงในแชต |
| ภาพเข้าแชตที่ถูก: ไม่มีปุ่มผูกแชตแล้ว แชตผูกเองจาก Prompt ที่คัดลอก หรือเมื่อ AI พิมพ์ "รหัสแชต" ที่ Ai-iclone แสดง | ✅ ทดสอบโค้ด · 🟡 ยังไม่ได้ดูในแชตจริง |
| ChatGPT ผ่านปลั๊กอิน Chrome (`tools/chrome_preview_bridge`): ส่งข้อความที่มี `AGENTS.md` แนบไปด้วยทุกครั้ง และส่งรูปจาก Preview | ✅ ส่งข้อความ · 🟡 การส่งรูปจริงเข้าแชตยังทดลองไม่ครบ |
| `Ai-iclone snap`: ส่งภาพ iClone ตอนนี้เข้าแชตได้อิสระ ไม่ติดเงื่อนไขเรื่อง/ท่อน | ✅ ทดสอบโค้ด · 🟡 ยังไม่ได้ส่งเข้าแชตจริง |
| เซฟ: ท่อนละ 1 ไฟล์ ผ่านเมนู File ไม่มีไฟล์สำรอง | ✅ |
| เรนเดอร์ก่อนผู้ใช้อนุมัติ | ห้าม |
