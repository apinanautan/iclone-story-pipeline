# เช็กลิสต์ต่อท่อน — แต่ละข้อ "ผ่านเมื่อ" (รวมจากคำสั่งผู้ใช้ทั้งหมดใน rules.md, 2026-11-15)

ใช้ทุกท่อน ทุกเรื่อง. ใส่เป็นลิสต์งานในแอปตอนเริ่ม, ติ๊กได้เมื่อมีหลักฐาน (ภาพ/ตัวเลข/ไฟล์). ไม่ผ่านครบ = ห้ามบอกว่าเสร็จ.

| # | เรื่อง | ผ่านเมื่อ |
|---|---|---|
| 1 | ตรงบท | ใครพูด/นั่ง/ยืน/อารมณ์ ตรงกับ .docx; เพศผู้พูดตรงเสียง; ไม่มีตัวที่บทไม่ได้พูดถึง |
| 2 | ฉากตามบรรยาย | บรรยายพูดถึงที่ไหน/ทำอะไร ภาพต้องเป็นที่นั้น (เช่น "ทำงานบริษัท" = ออฟฟิศนั่งหน้าคอม); ฉากต่างกัน = แยก N.1/N.2 |
| 3 | เสียง | แถว Project > Sound มี **ท่อนN.wav ของท่อนนี้** เริ่มเฟรม 0 (ลบเสียงเก่าที่ติดมากับฉากแล้ว) แล้วเซฟทันที; ตรวจจากแถว Sound ในไทม์ไลน์ (ห้ามใช้ RenderAudio) |
| 4 | ปาก | ขยับเฉพาะคนพูด ตรงช่วงที่พูด; คนอื่นปากนิ่ง |
| 5 | โมชันช้า | ทุกคลิป speed 0.15–0.30 ยืดคลิปเดียวเต็มช่วง; ไม่มีท่ายุกยิก/ดีใจใหญ่สำหรับคนฟัง; วัดวิดีโอได้ ≈30 px/s (ไม่เกิน ~40) |
| 6 | คนไม่พูด | หัวขยับ (Look front) + Look At มองคนที่ควรมอง + ยิ้ม/สีหน้าตามบท + กระพริบตา |
| 7 | ไม่ทะลุ | ภาพข้าง+หลังของคนนั่ง/พิง: ไม่ทะลุเก้าอี้/โต๊ะ ไม่ลอย มือวางบนของจริง (คีย์บอร์ด/ตัก) |
| 8 | มุมกล้อง | ไม่ซ้ำท่อนก่อน; เห็นหน้า 3/4 (ไม่ใช่ท้ายทอย); ครึ่งตัว/อกขึ้นไป ไม่เห็นขา; ไม่มีช่องว่างกลางเฟรม; ไม่มีของบังหน้า; **ไม่มีคนโดนขอบเฟรมตัดครึ่ง (ผม/ไหล่โผล่มานิดเดียว)** |
| 8b | เห็นคนพูด | ระหว่างที่ตัวละครพูด ทุกช็อตเห็นหน้าคนพูด (เปลี่ยนมุมได้); ตัดไปคนฟังได้เฉพาะช่วงเงียบ/บรรยาย |
| 8d | เห็นสีหน้า | ทุกช็อตใหม่ถ่ายภาพนิ่งกลางช็อตดูก่อนส่ง: เห็นหน้า ไม่ใช่โปรไฟล์ ไม่มีผมบังตา สีหน้า(เช่น หงุดหงิด)อ่านออก |
| 8c | หลักมุมกล้อง | ทำตาม `docs/CAMERA_GUIDE.md` (ขนาดภาพ เลนส์ 180° จังหวะตัด 2 คีย์/ช็อต ไฟ fill) |
| 9 | กล้องขยับ | ทุกช็อตซูม/แพนช้า ๆ; ตัดช็อตตรงช่วงเงียบ; ใช้ Cam_A/Cam_B สลับ |
| 10 | Switch | dropdown กล้องบน toolbar = **Switch**, หัวเล่นเฟรม 0 ก่อนให้ผู้ใช้ดู/ก่อนเรนเดอร์ |
| 11 | เซฟ | เซฟผ่าน GUI เท่านั้น (Save Project / Save Project As) ชื่อ `ท่อนN.iProject` หรือ `ท่อนN.1/N.2`; เวลา+ขนาดไฟล์บนดิสก์เปลี่ยนจริง; เปิดซ้ำได้ |
| 12 | ไฟล์ final เท่านั้น | โฟลเดอร์เซฟ/วิดีโอไม่มี _v2, _test, Restore, preview ค้าง (ย้ายลงถังขยะ) |
| 13 | ให้ผู้ใช้ดู | **ช่วงเล่น (หมุดเขียวใต้วิวพอร์ต) ต้องครอบคลุมทั้งท่อน 0 ถึงจบ** แล้วค่อยบอกให้กด Play; อยู่หน้าคอม = บอกให้กด Play ใน iClone (ไม่ส่ง 480p); บอกว่าอยู่มือถือ = ส่ง 480p |
| 14 | เรนเดอร์จริง | ทำหลังผู้ใช้บอกผ่านเท่านั้น; 1920×1080 60fps, ใช้ Switch; ffprobe ตรง 60fps + ความยาวตรง; มีเสียง ไม่เงียบ; ภาพแต่ละช็อตเป็นกล้องต่างกัน → `E:\Video\<เรื่อง>\N.mp4` |
| 15 | ไม่ค้าง | ช้าผิดปกติ = ถ่ายจอดูทันที (หน้าต่างถาม, Save dialog, watcher BLOCKED) ไม่นั่งรอ |
