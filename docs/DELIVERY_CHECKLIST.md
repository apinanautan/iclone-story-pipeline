# DELIVERY CHECKLIST — ทำให้ครบทุกข้อก่อนบอกผู้ใช้ว่า "เสร็จ"

ผู้ใช้สั่งไว้แล้วทุกข้อด้านล่าง (2026-11-11): **ห้ามให้ผู้ใช้ต้องสั่งซ้ำ**. ทำทีละข้อตามลำดับ ติ๊กด้วยหลักฐานจริง
(ไฟล์/ภาพ/ตัวเลข) ไม่ใช่ความรู้สึก ข้อไหนยังไม่ทำให้บอกว่า "ยังไม่เสร็จ" และทำต่อเอง ไม่ถามว่าจะทำไหม.
แหล่งกฎเต็ม: docs/rules.md, สกิล iclone-key, docs/event_clip_workflow.md.

## A. ก่อนสร้าง
- [ ] เสียงท่อน: ใช้ `Desktop\ดวงเมียน้อย_ดาต้าเสียง\เสียงที่ตัดแล้ว\ท่อนN.wav` ที่ผู้ใช้ให้ตัดไว้แล้ว (ห้ามถามช่วงนาทีซ้ำ)
- [ ] อ่านเนื้อเสียง/บทของท่อน แล้วแบ่ง event ตาม "การกระทำหลักเปลี่ยน" (ไม่แบ่งตามกล้อง/คนพูด)
- [ ] ฉากเปิดจาก `G:\ไดรฟ์ของฉัน\ดวงเมียน้อย\ฉาก\` (หรือไฟล์ที่ผู้ใช้ให้) ห้ามเซฟลง G: ห้ามทับ N.iProject ของผู้ใช้
- [ ] เปิด iClone ใหม่: ลบ run/*.py ที่ค้างก่อน → อ่านข้อความหน้าเตือนทีละอัน (UIA) → watcher STARTED

## B. ตัวละคร / โมชั่น
- [ ] โมชั่น: ช้าได้ (0.2–0.5) ยืดเป็นคลิปเดียวให้ครบความยาว + **หาง 5 วินาที**; ไม่ขยับเยอะ; **ห้ามท่าเดิน**
      (ยกเว้น event เดินจริง) วัด root drift ก่อนเลือก; โมชั่นงานจากโฟลเดอร์ `ทำงาน`; ห้าม Daily Life
- [ ] คัดลอกไฟล์โมชั่นมาไว้ในเครื่องก่อนใช้ (กัน iClone พังตอนเซฟ)
- [ ] มือผ่อนคลาย: Hold Gently.iHand ที่ต้นช่วง
- [ ] ไม่มี Look At ที่ทำให้หัวบิด (ลบด้วย RemoveAllAnimations แล้วโหลดโมชั่นใหม่) / ถ้าต้องมองคนอื่นให้ผูก Head bone
- [ ] หัวขยับเล็กน้อยช้า ๆ (ไม่นิ่งเป็นรูปปั้น) + กระพริบตาอัตโนมัติ (SetAutoBlinkName('Normal'))
- [ ] สีหน้าตามบท (expression) ไม่ใช่หน้านิ่งโกรธ
- [ ] ไฟหน้า (face light) ให้ทุกตัวละคร: spot, RRgb(255,236,214), multiplier 0.04
- [ ] ปาก: ตัวที่พูดเอง → Create Script > Audio File แล้วตัด viseme เฉพาะช่วงพูดจริง; ท่อนบรรยายล้วน = ปากเงียบ (บอกผู้ใช้ชัดเจน)

## C. เสียง (ทำทันทีหลังเซฟครั้งแรก ไม่ต้องรอสั่ง)
- [ ] หัวเล่นที่เฟรม 0 → Ctrl+I → ท่อนN.wav → แถว Project > Sound ขึ้นชื่อคลิปที่เฟรม 0
- [ ] Timeline ยาว = เสียง + 5 วินาที (SetProjectLength + SetEndTime) และซูม Timeline ให้เห็น 0→จบ
- [ ] เซฟซ้ำหลังนำเสียง และตรวจเวลา/ขนาดไฟล์บนดิสก์ (ไม่ใช่แค่ "save OK")

## D. กล้อง (ทำทุกครั้ง ไม่ใช่ "ยังไม่ได้")
- [ ] เลนส์ 80 หรือ 100 mm เท่านั้น; ครึ่งตัว/MCU/OTS ไม่เอาเต็มตัว
- [ ] ช็อตคนพูด/ทำงานเปิด DOF (focus ที่ตัวละคร); ช็อตวิวกว้างไม่เปิด DOF
- [ ] ทุกช็อตเคลื่อนช้ามาก (zoom/orbit ≤2°, ความเร็วคงที่ ไม่กระชาก) คีย์ทุก 0.25 วินาที
- [ ] อย่างน้อย 2 กล้องสลับด้วย Switcher (AddSwitchCameraKey) ตัดแข็ง ~1 คัตต่อ 5 วินาที; ช็อตของคนเดิมต้องต่างขนาด/มุม
- [ ] คนอยู่กลางเฟรม เห็นหน้าชัด ไม่มีมือ/ไหล่บังเลนส์ ไม่ติดกำแพง/ชั้น (ซ่อนของที่บังด้วย RScene.Hide)
- [ ] ตั้งกล้องผ่านไฟล์ iCam Template (RFileIO.LoadFile) ห้ามลบกล้องด้วย RemoveObject ก่อนเซฟ
- [ ] ตั้งมุมมองเป็น "Switcher" ให้ผู้ใช้กด Play ได้เลย
