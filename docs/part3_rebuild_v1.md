## แผนโมชั่นแบบแสดงเป็นมนุษย์
A. ช่วงพ่อและเมียน้อย: พ่อหยุดคำพูด → สายตาละจากแม่ → หายใจ → เตรียมเท้ารับน้ำหนัก → หัวหันก่อนลำตัว → เริ่มก้าวโดยเร่งจากหยุดนิ่ง → เมียน้อยตอบสนองและตามช้ากว่าพ่อ → เข้าใกล้ประตู. ใช้ single root-motion clip ต่อเนื่องเมื่อทำได้ ไม่ต่อ Walk หลายอันจน reset. ไม่ fix speed=0.4 แบบเก่าก่อนตรวจ foot plant. ไม่จำเป็นต้องถ่ายด้านหลังไปจนสุดประตู; cut ไป reaction แทน.
B. ช่วงแม่/ลูก: แม่มองพ่อจากไป → มองลูกด้วยสายตาก่อนหมุนตัว → ลูกคนแรกมองกลับ → ลูกอีกคนค่อยตาม → แม่โน้มตัว/โอบปลอบอย่างสัมผัสจริง → คลายอ้อมแขน/ถ่ายน้ำหนัก → ก้าวแรก → ลูกเดินตามเหลื่อมเวลาและก้าวไม่เท่ากัน → จบในเฟรม. ถ้าท่ากอดจากคลังสัมผัสไม่ผ่าน ให้เปลี่ยนเป็นมือจับไหล่/ประคองจาก close angle แทน ไม่ใช้ท่าปลอม.
C. ห้ามให้ 5 ตัวละครใช้ท่า Stand/Walk สปีดหรือ phase เดียวกัน; เลือกจาก motion_catalog โดยเล่นตัวอย่างดูเอง ไม่เชื่อชื่อ clip. ทุก stand-walk join ต้อง match pose/root speed/direction/foot phase, มี crossfade เท่าที่เหมาะสม. หลีกเลี่ยงการ transform หมุนทั้งตัวเร็ว ๆ.
D. แยก action เป็น dramatic beats และใช้ coverage/cutaway; **แบ่งช็อตกล้องไม่จำเป็นต้องหั่นโมชั่นออกเป็นหลาย clip**. ถ้าแยก takes จริงต้องเช็ก world position, yaw, ก้าว, สายตา, screen direction ทั้งสองฝั่งของคัต.

## 10-Pass Human Performance QA (ตารางเช็กจริง)
| รอบ | การตรวจ | หลักฐานผ่าน |
|---|---|---|
| 1 Intention | ขยับเพราะอารมณ์หรือเหตุการณ์ ไม่สุ่ม | action beat ตรงเสียง |
| 2 Anticipation | ไม่เดิน/หันทันทีแบบหุ่น | gaze, breath, shift ก่อนก้าว |
| 3 Mechanics | หัว/ไหล่/สะโพก/เท้าสัมพันธ์กัน | ดูเฟรมต่อเนื่อง ไม่เห็นแข็ง/ลอย |
| 4 Transition | stand-walk หรือ walk-stand ไม่กระตุก | ตรวจเฟรมก่อน/หลัง join และ foot plant |
| 5 Root/path | ไม่ reset/teleport/ชน/ทะลุประตู | ตรวจ world path + คลิปต่อเนื่อง |
| 6 Rhythm | จังหวะเด็ก/ผู้ใหญ่ไม่ซิงก์เทียม | offset ก้าว/ท่าตามบท |
| 7 Gaze/lips | พ่อพูดตรงปาก; เด็กมองคนถูก | sound-aligned mouth/eyeline |
| 8 Hands/contact | มืออ่อนเป็นธรรมชาติ สัมผัสน่าเชื่อ | แขน/นิ้ว/ไหล่ไม่ทะลุ |
| 9 Coverage | ไม่มีมุมกว้างไร้เหตุผล/คนหลุด | ดูหัว-ไหล่-ฉากหลังทุกเฟรม |
| 10 Edit/ending | screen direction/ก้าวต่อคัต/ฉากจบ | match-on-action + payoff เต็ม |

ทุกรอบลง timecode + ตัวละคร + สิ่งที่เห็นจริง + สาเหตุที่คาด + วิธีแก้ + ผลตรวจหลังแก้ใน checklist. ใช้ภาพเคลื่อนไหวจริง 30fps ขึ้นไปควบกับ Timeline/keys. frame-diff เป็นเพียงตัวชี้รอยตัด/เฟรมต่าง ไม่พิสูจน์ว่าแอนิเมชันผิด. หลังแก้ 1 จุด ต้อง regression-check ช็อตข้างเคียงและกลับไปเช็ก 10 pass ใหม่. **ยังไม่ผ่านหากการแสดงดูไม่จริง** แม้ไม่มี error.
