# กรงกตัญญู — แผนภาพช่วงเปิด 1:07.2

ใช้เสียง `audio_output/1.mp3` ของเรื่องความยาว 164.3 วินาที เริ่มที่ 0.0 และตั้งช่วงทดลองถึง 67.2 วินาที ซึ่งอยู่ระหว่างเสียงเงียบ 66.79–67.81 วินาที คิวภาพด้านล่างเป็นร่างจากลำดับเนื้อหาในบท ยังต้องฟังเทียบเสียงก่อนล็อกจังหวะตัดและช่วงขยับปาก

| เวลา | ภาพและการแสดง |
|---|---|
| 0.0–12.0 | เปิดที่บ้านของทั้งคู่ เห็นสมจิตกับอุไรในภาพเดียว ขยับกล้องเข้าช้า ๆ แนะนำความสัมพันธ์ |
| 12.0–24.0 | เข้าใกล้สมจิต ใช้สีหน้าสงบ ให้เวลาคนดูจับอารมณ์ระหว่างคำบรรยาย |
| 24.0–36.0 | สลับมาที่อุไร ให้เธอเหลือบมองสามี ใช้ปฏิกิริยาเล็ก ๆ |
| 36.0–47.5 | กลับภาพคู่ เลื่อนออกเล็กน้อยให้เห็นทั้งสองคนรับฟังเรื่องลูกด้วยกัน |
| 47.5–54.3 | กลับมาที่ใบหน้าสมจิต ถ้าเสียงช่วงนี้ตรงกับบทพูดจริง ให้รั้งภาพไว้ที่เขาและสร้างปากเฉพาะช่วงพูด |
| 54.3–67.2 | กลับภาพคู่เพื่อปิดช่วงเปิด ถ้าเสียงเปลี่ยนไปที่ญาติ ให้ใช้ช็อตญาติหลังยืนยันตัวละครและช่วงพูด ตัดจบที่ช่องเงียบ |

ฉบับทดลองเริ่มด้วยสมจิตกับอุไรวัย 40 จากไฟล์ตัวละครต้นทาง และฉากบ้านต้นทาง จุดยืนและมุมกล้องในสเปกเป็นจุดทดลอง ต้องให้ผู้ใช้ตรวจภาพก่อนบันทึกเป็นจุดอนุมัติของเรื่อง

งานที่ต้องตรวจใน iClone ได้แก่ ภาพกลางช็อตและขอบเฟรม การเคลื่อนกล้องกับท่าทาง เสียงหลักที่เฟรม 0 ช่วงเล่นจนถึง 1:07.2 และปากของผู้พูดตามบทจริง
