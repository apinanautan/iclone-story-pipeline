- อ่านบท .docx ช่วงนี้ แล้วจัดฉากตามบท ไม่ใช่ตามรายชื่อตัวละคร: ใครนั่ง ใครยืน ใครพูด เพศของคนพูดต้องตรงกับเสียง และใครรู้สึกอย่างไร

  ถ้าฉากเปลี่ยนจริง ให้แยกไฟล์เป็น N.1 / N.2 ห้ามแยกเพียงเพราะเปลี่ยนกล้องหรือเปลี่ยนคนพูด
- ใช้ชื่อตัวละครตาม story.json เท่านั้น ห้ามเดาตัวละครจากชื่อไฟล์ (เช่น ไฟล์ สุดา/วารี ของรักลำเอียงเคยสลับกัน)
  ถ้าในฉากมีตัวละครสำรวจ (เช่น Sunee) ให้ซ่อนไว้ ห้ามใส่แอนิเมชันให้
- บอกผม: ฉาก, นักแสดง, ใครพูดช่วงไหน, ที่เซฟ ({SAVE}\ท่อนN.iProject ต้องเป็นไฟล์ใหม่ ห้ามทับไฟล์ของเรื่องอื่น)
- ไม่ต้องเขียนแผนยาว ไม่ต้องสร้างไฟล์แผนแยกต่อเรื่อง ให้จดลง docs/CURRENT_STORY.md เท่านั้น

- จะได้ไฟล์ .wav 48kHz และ .json ที่มีเวลาของแต่ละช่วงในท่อน ใช้ไฟล์นี้เท่านั้น ห้ามเขียนสคริปต์ ffmpeg หรือ whisper เอง
- คำที่ถอดได้ให้แก้ให้ตรงบท .docx แล้วเก็บลง story.json ที่ parts[N].transcript ในรูปแบบ {t,who,text,about}
- ก่อนใช้ ให้เช็กว่าความยาวไฟล์เสียงถูกต้อง และเป็นเสียงของเรื่องนี้ (เคยหยิบไฟล์ 3.wav ของเรื่องเก่ามาใช้ผิด)

══════════ สเต็ป 3 — เขียน spec ท่อน ══════════
ก๊อป parts/_example.json ไปเป็น parts/<เรื่อง>_<N>.json (รูปแบบเต็มดูได้ใน docstring ของ scripts/ic8_part.py)
ตั้งค่า wav, lines (ใครพูดเวลาไหน), cast (spot/motion/lookfront/lookat/face) และ shots ตามกฎด้านล่าง
รัน `python scripts/ic8_part.py parts/<spec>.json audio` เพื่อดูช่วงเงียบ แล้วรัน `... check` จนขึ้น OK
ห้ามเขียนสคริปต์จัดฉากหรือกล้องเองเพื่อเลี่ยง ic8_part.py ถ้าสคริปต์กลางขาดความสามารถอะไร ให้แก้ที่สคริปต์กลาง

══════════ สเต็ป 4 — สร้างงานใน iClone ══════════
เปิด iClone เอง ไม่ต้องให้ผมเปิด ตัวเฝ้างาน (watcher) จะโหลดผ่าน iCloneStoryBridge ห้ามลบ bridge นี้
popup ให้ปิดด้วย scripts/ic8_startup_popup_guard.ps1 หรือ ic8_ui.ps1 ห้ามคลิกเอง
ถ้า watcher ขึ้น BLOCKED ให้ลบไฟล์ .py ที่ค้างใน run\ แล้วเปิด iClone ใหม่
รันทีละขั้น และตรวจ log ของแต่ละขั้นก่อนไปขั้นถัดไป:
  ic8_part.py <spec> open → cast → pose → sound → cams   (เมื่อแก้ค่าแล้ว: `<step> --from`)
หลังสั่ง open ให้เซฟผ่าน GUI ทันทีครั้งแรก (iClone ปิดตัวเองได้โดยไม่เตือน)

══════════ สเต็ป 5 — ตรวจภาพนิ่ง (บังคับทุกครั้ง) ══════════
ภาพนิ่งต้องมาจาก `ic8_part.py <spec> cams` เท่านั้น ห้ามใช้สคริปต์ทดลองหรือสคริปต์ RenderImage ที่เขียนเอง
(ภาพทดลองกรงกตัญญูที่เห็นเต็มตัวยืนเรียงกัน มาจาก ic8_trial_krong_stage.py ซึ่งข้ามขั้น check)
ขั้น cams จะถ่ายภาพจากกล้องของช็อตนั้น (Cam_A/Cam_B ตรงกับ Switcher) ประมาณ 1 ภาพต่อวินาที (3–8 ภาพต่อช็อต)
ก่อนถ่ายทุกภาพจะรอให้ iClone อัปเดตเสร็จ แล้วเทียบตำแหน่งกล้องกับแผน; ต้องตรวจว่าภาพครบทุกช็อต (ไม่มีภาพ/ขาดจำนวน = FAIL) และรัน still_check.py ตรวจความผิดปกติของการเลื่อนภาพ
STILL_MISMATCH หมายถึงตำแหน่งกล้องผิดเกิน 3 ซม. ต้องหยุดถ่ายทันที; JUMP / FLIP เป็นสัญญาณให้ตรวจภาพและโมชั่น ไม่ใช่หลักฐานว่ากล้องจริงกระโดด ต้องเทียบ camera keys และ log ก่อนสรุป ห้ามเอาภาพไปส่ง ให้รัน `cams --from` ใหม่
ได้ contact sheet หน้า 1920x1080, 3x3 ภาพ, ป้ายกำกับ S03-02 12.4s (1 แถว = 1 ช็อต)
ดูทุกภาพตามรายการในสกิล review-stills แล้วเขียนลิสต์ช็อตจากสิ่งที่เห็นในภาพจริง ไม่ใช่จากแผน ถ้าไม่ตรงกับแผน ให้แก้ spec แล้วรัน `cams --from` จนผ่าน
คนที่นั่งหรือพิง: ถ่ายภาพจากด้านข้างและด้านหลังเพิ่ม เพื่อเช็กว่าไม่ทะลุเก้าอี้ ไม่ลอย และมือวางบนของจริง
ส่ง contact sheet ให้ผม พร้อมคำอธิบายช็อตละ 1 บรรทัด และติ๊กเช็กลิสต์ข้อ 1–9 พร้อมหลักฐาน
→ หยุดรอผมบอก "ผ่าน" (ถ้าผมให้แก้ ให้แก้แล้วกลับมาทำสเต็ป 5 ใหม่) ห้ามเรนเดอร์ทดสอบ

══════════ สเต็ป 6 — ลิปซิงก์ ══════════
`ic8_part.py <spec> lip` จะทำปากให้คนพูดทีละคน ผ่าน Animation > Create Script > Audio File โดยใช้เสียงเต็มของท่อน แล้วลบส่วนที่อยู่นอกช่วงที่คนนั้นพูด
คนที่ไม่พูดต้องปากนิ่ง ตรวจว่าจำนวน Viseme ของคนพูดมากกว่า 0 และดูภาพนิ่งกลางประโยคว่าปากขยับจริง
Look front, Blink และ LoadAudioToObject ไม่ถือว่าเป็นการพูด

══════════ สเต็ป 7 — เซฟและให้ผมดู ══════════

เช็กว่าเวลาและขนาดไฟล์บนดิสก์เปลี่ยนจริง และชื่อหน้าต่างไม่มีเครื่องหมาย *

1. ตัวละคร: เลนส์ 80 หรือ 100 mm เท่านั้น เปิด DOF โฟกัสที่ตัวละคร ภาพต้องเห็นแค่อกขึ้นไป

4. ต้องเห็นหน้ามุม 3/4 ห้ามเห็นแค่ท้ายทอย ภาพด้านข้าง (โปรไฟล์) ให้สั้น ห้ามมีผมหรือของบังหน้า

   ช่วงบรรยาย ให้ถ่ายคนที่ถูกพูดถึง (ใน about) ตัดไปคนฟังได้เฉพาะตอนเงียบหรือตอนบรรยาย
