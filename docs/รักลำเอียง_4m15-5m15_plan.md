## เกณฑ์ดำเนินงาน
1. เตรียมเสียง / แยก event ที่จุดพักจริงผ่าน `cut_audio.py`, เก็บ master WAV ต่อเนื่อง
2. เปิดฉากต้นทางของแต่ละเหตุการณ์, scan ด้วย `ic8_scene_scan.py`, กำหนด spots/cams จากตำแหน่งจริง
3. เขียน spec ใน `parts/`, `ic8_part.py check` ต้องผ่าน; ห้ามสร้างกล้อง/คีย์ก่อนผ่าน
4. `open -> cast -> pose -> sound -> cams` โดยใช้ shared scripts; การแสดงช้า สีหน้าชัด, 80/100mm close MCU/3-4
5. ส่ง contact sheet ตรวจ; หยุดก่อน lip-sync หรือเรนเดอร์ตาม master skill. เสียงช่วงนี้เป็นบรรยายทั้งหมด: ไม่ต้องใส่ AccuLips ให้ตัวละครที่ไม่มีบทพูด
6. Save As เฉพาะชื่อไฟล์ใหม่ผ่าน GUI แล้ว verify; ห้าม overwrite ท่อน6/7 เดิม
