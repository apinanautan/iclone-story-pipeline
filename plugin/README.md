# ปลั๊กอิน GPT สำหรับ Ai-iclone (เวอร์ชัน 1.6 ขึ้นไป)

โฟลเดอร์นี้มีทุกอย่างที่ต้องใช้สร้างปลั๊กอิน (GPT) ตัวใหม่ ให้มันรู้ทันทีว่าต้องทำงานกับ Ai-iclone ยังไง

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `INSTRUCTIONS.md` | **พร็อมป์** คัดลอกทั้งหมดไปวางในช่อง Instructions ของปลั๊กอิน |
| `mcp.json` | ใช้เฉพาะกับโปรแกรม AI อื่นที่ต่อแบบ MCP ได้ (ไม่ต้องใช้ถ้าใช้ผ่าน MyComp Bot) |

## วิธีทำบนเครื่องที่ยังไม่มีโปรเจกต์
1. โหลด `Ai-iclone.exe` จาก https://github.com/apinanautan/iclone-story-pipeline/releases/latest แล้ววางไว้ในโฟลเดอร์ "ดาวน์โหลด"
2. เครื่องต้องมี Python 3 (ถ้าไม่มี ให้ลงจาก python.org และติ๊ก "Add to PATH")
3. สร้างปลั๊กอิน GPT ใหม่ แล้ววางข้อความทั้งหมดจาก `INSTRUCTIONS.md` ลงในช่อง Instructions
4. เชื่อมปลั๊กอินเข้ากับ **MyComp Bot** (ตัวที่ให้ ChatGPT สั่งงานเครื่องเราได้) GPT จะใช้เครื่องมือ `shell` ของ MyComp Bot เปิด Ai-iclone.exe เอง ไม่ต้องลงอะไรเพิ่ม
5. พิมพ์บอก GPT ว่า "เริ่มเลย" มันจะเปิด Ai-iclone ซึ่งจะโหลดตัวโปรแกรมทั้งหมดไปไว้ที่ `%LOCALAPPDATA%\Ai-iclone` เองในครั้งแรก แล้วบอกว่าต้องทำอะไรต่อ

ไม่ต้องแก้พร็อมป์ตอนโปรแกรมออกเวอร์ชันใหม่ เพราะกฎละเอียดของแต่ละข้ออยู่ในตัวโปรแกรม และโปรแกรมอัปเดตตัวเองได้
